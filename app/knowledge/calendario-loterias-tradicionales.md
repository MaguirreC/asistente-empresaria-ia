# Loterías principales (tradicionales): calendario semanal

Estas son las 15 loterías tradicionales principales, cada una con un **día fijo
de la semana** en que sortea. A diferencia de los sorteos diarios de chance
(Chontico, Pick 3, Sinuano, etc.), estas loterías **solo juegan una vez por
semana**, en la noche.

| Lotería | Día de sorteo |
|---|---|
| Cundinamarca | Lunes |
| Tolima | Lunes |
| Cruz Roja | Martes |
| Huila | Martes |
| Manizales | Miércoles |
| Meta | Miércoles |
| Valle | Miércoles |
| Bogotá | Jueves |
| Quindío | Jueves |
| Medellín | Viernes |
| Risaralda | Viernes |
| Santander | Viernes |
| Boyacá | Sábado |
| Cauca | Sábado |
| Extra de Colombia | Sábado |

No hay sorteo de estas loterías tradicionales los domingos.

## Cómo usar esta información

Este calendario explica **por qué** una lotería no aparece en el listado de
hoy: por ejemplo, si hoy es miércoles, Cundinamarca no va a estar disponible
porque juega los lunes.

**Para saber qué se puede jugar HOY, siempre se debe consultar la herramienta
de loterías del día — nunca responder solo con este calendario.** Este
documento sirve para explicar el patrón semanal, no para decir qué está
abierto en este momento. Fechas especiales, festivos o cambios de última hora
pueden alterar el calendario, y esos cambios solo los refleja la consulta en
vivo.

**El día de la semana de HOY también sale de esa herramienta, nunca se
calcula ni se adivina a partir de la fecha.** Ya pasó que se dedujo mal (se
dijo "martes" para una fecha que en realidad era miércoles). Si la pregunta
necesita saber qué día es hoy para cruzarlo con este calendario, hay que
consultar primero la herramienta de loterías del día y usar el día que ella
entrega.

## Ejemplo de cómo combinar ambas fuentes

> Usuario: ¿cuándo juega Cundinamarca?
>
> Cundinamarca juega los **lunes**. Hoy es [día de hoy, según la herramienta],
> así que hoy no está disponible. [Si se consultó la herramienta y hoy es
> lunes, confirmar que sí aparece en el listado del día.]
