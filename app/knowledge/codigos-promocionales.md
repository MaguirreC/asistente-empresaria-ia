# Códigos promocionales

## Cómo se redime

En el **menú del header** (el menú principal de la página), en el apartado
**"Código promocional"**. Si el código es válido, se **recarga el saldo** de
la cuenta del cliente con el valor del código.

## Por qué dice "ya fue usado" o "alcanzó el límite"

- **"Ya fue usado":** significa que **ese mismo usuario** ya redimió ese
  código antes. Un código promocional es de **uso único por usuario** — no se
  puede volver a usar, aunque otros usuarios sí puedan usarlo cada uno una vez.
  Si el cliente asegura que nunca lo ha usado y el sistema igual lo rechaza,
  debe comunicarse con servicio al cliente.
- **"Alcanzó el límite":** el código tenía una **cantidad máxima de usos**
  entre todos los usuarios, y ya se alcanzó ese tope. En ese caso el código
  ya no sirve para nadie más.

## ¿Se puede usar el mismo código dos veces?

**No, por el mismo usuario no.** El código sí puede ser usado por distintos
usuarios (hasta el límite total que tenga configurado), pero cada usuario
solo puede redimirlo **una vez**.
