# Ingreso, contraseña y bloqueo de cuenta

## Si olvidó la contraseña

1. En la pantalla de ingreso, pulsar **"Olvidé mi contraseña"**.
2. Ingresar el **correo registrado**.
3. Llega un correo con un **código** y las indicaciones para restablecerla.
4. Seguir esas indicaciones para crear la contraseña nueva.

## Cambiar la contraseña estando dentro de la cuenta

Abrir el **menú del perfil** y elegir **"Cambiar contraseña"**. Pide la
contraseña **actual** y la **nueva**.

## Sobre el código que llega por correo

El código se usa **para restablecer la contraseña**, no como paso normal para
entrar. Un usuario que ya tiene su contraseña ingresa solo con correo y
contraseña.

## Cuenta bloqueada

La cuenta se bloquea automáticamente **después de 5 intentos fallidos** de
contraseña. Antes del último intento el sistema avisa que queda uno.

Para desbloquearla, el usuario debe **comunicarse con servicio al cliente
radicando una PQRS**. No se desbloquea sola ni desde la página.

## Mensaje "Usuario inactivo"

Significa que la cuenta está desactivada. Los motivos más comunes son:

- La cuenta **nunca se activó** después del registro.
- Se **bloqueó por superar el máximo de intentos** de contraseña.
- Otro motivo administrativo.

En todos los casos, la vía es **radicar una PQRS** para que revisen el caso. Si
el usuario cree que nunca activó la cuenta, primero puede pedir que le reenvíen
el correo de activación.
